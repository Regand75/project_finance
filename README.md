SPA приложение, разработанное на чистом JS. Тематика - проект для учета доходов и расходовс с использованием сторонник бибилиотек - таких как Bootstrap  (для стилизации) , Chart.js (для построения диаграмм).

Основной функционал:
- позволяет добавлять категории доходов и расходов;
- редактировать, удалять, сортировать по датам;
- выводить статистику в виде графиков для удобного визуального восприятия.

Запуск приложения:  
- установить зависимости для backend и frontand проекта (команда npm install);
- запустить серверную часть из папки backend/ и клиентскую часть из папки frontend/ (комнда npm start);
- перейти по URL разработческого сервера.
