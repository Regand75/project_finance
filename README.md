Это SPA приложение для учета доходов и расходов, написанное на чистом JS, с использованием сторонник бибилиотек - таких как Bootstrap  (для стилизации) , Chart.js (для построения диаграмм).
Функционал позволяет добавлять категории доходов и расходов, редактировать, удалять, сортировать по датам и выводить статистику в виде графиков для удобного визуального восприятия.
Для запуска проекта необходимо установить зависимости для backend и frontand проекта (команда npm install)
Запустите серверную часть из папки backend/ и клиентскую часть из папки frontend/
Перейдите по URL разработческого сервера
